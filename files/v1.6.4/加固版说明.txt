《坦克世界》战绩查询 — Windows 版【加固版 · 第4版】
版本：外部 1.6.4 / 内部 25（第4版）

────────────────────────────────
一、怎么用
────────────────────────────────
双击「启动.bat」，或直接双击 WotBoxMac.exe。

· 自包含程序，.NET 8 运行时已打包在内，**无需安装任何东西**。
· 首次打开可能弹「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」。
· **本版已做加固**，可能被杀毒软件误报（混淆的常见副作用），
  选择「仍要运行」即可。

────────────────────────────────
二、重要：assets 文件夹不能删
────────────────────────────────
程序目录里的 **assets 文件夹是图片素材**（坦克图、背景图等），
必须和 WotBoxMac.exe 放在同一层。移动程序时**整个文件夹一起移动**，
不能只拷 exe，否则界面里的坦克图片会显示不出来。

────────────────────────────────
三、数据存在哪
────────────────────────────────
    %APPDATA%\WotBoxMac\
（资源管理器地址栏粘贴 %APPDATA% 回车即可打开）

────────────────────────────────
四、自检
────────────────────────────────
双击「自检_测试数据接口.bat」，用测试账号 Champion_Ace 跑一遍，
确认盒子接口、官方接口、评级榜接口都通。需要联网。

────────────────────────────────
五、本版（第4版）改了什么
────────────────────────────────
1. **程序图标 =「瞄准镜」军团团徽**（从坦克世界官网取的官方团徽
   emblem_256x256.png，做成 7 档尺寸的 exe 图标）。
2. **加固处理（防反编译）**：
   · 字符串加密 —— 全部 1060 条文本常量（含所有接口地址、提示语）已加密，

3. **新增「自动更新」能力**（本版集成，见下节）。

────────────────────────────────
六、自动更新（本版新增）
────────────────────────────────
· 程序启动后会**在后台静默检查**新版本，不弹窗、不打扰使用。
· 只下载「内容有变化」的文件，下完校验 SHA-256，**下次启动时**自动替换生效。
· 若新版本启动失败，会**自动回滚**到旧版本。
· 想关掉：设置页 →「自动更新」开关（默认开）。
· 说明：自动更新依赖 GitHub 上的版本清单；托管仓库建好后即生效。
  *（本版为本地打包的最终 Windows 版，GitHub 上传待定。）*

────────────────────────────────
七、关于加固效果的诚实说明
────────────────────────────────
· .NET 程序是 IL 中间语言，**运行时必然会在内存中还原成可读形态**，
  因此没有任何方案能 100% 防住专业逆向。
· 本加固的目标是「**让普通人、用现成反编译工具的人读不懂、改不动**」。
· 已实测：接口地址等敏感字符串在 dll 中已无明文；类型/方法名已不可读；
  界面与全部功能（查询、阵容、导出、点亮计算等）均正常。
· 保留未混淆的仅有少数必须按原名加载的对象（主窗口、App 等），属必要保留。

────────────────────────────────
八、功能一览
────────────────────────────────
战绩查询（含整页导出）· 完整账号数据 + 战绩排行榜 · 战斗分析（15v15 阵容）
日志查询（含导出）· 军团（含导出图片）· 点亮计算（距离轴 + 反推 + 机制说明）
工具箱（开发中）· 设置（四卡片，导出清晰度 1×～4×）

车辆数据覆盖 1～11 级（含 28 辆 11 级车）。

────────────────────────────────
九、注意
────────────────────────────────
程序依赖两个外部数据源（盒子 wotbox.ouj.com、官网 wotgame.cn），
都不是我们能控制的；若某模块突然没数据，多为对方接口调整所致。
本程序为军团内部使用的查询工具，非官方软件。
